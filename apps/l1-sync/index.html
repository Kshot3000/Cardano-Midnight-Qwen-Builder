ℹ️ What an observation is

An observation is the cNightObservation.processTokens extrinsic Midnight runs to fold a Cardano L1 block (and any token events inside it) into Midnight. The dashboard reads it straight off-chain from the public explorer.

🧠 About this dashboard

Data: public NightForge explorer API (mainnet.nightforge.jp) — /api/extrinsics, cross-checked against the Cardano mainchain tip from Koios (data.cardano.org/k/api/v1/tip). The sync health score is a transparent rubric (tight lag, steady cadence, broad coverage, asset flow), computed in sync.js and covered by unit tests. If the explorer stops exposing a field, this page shows – rather than inventing a number. No private data — every observation is public on Midnight.

Lag in blocks is exact (observed L1 block vs Koios tip height). Lag in seconds is an estimate at Cardano mainnet's 20-second block time and is labeled as such. This is an informational tool — verify finality and amounts against official sources before relying on them.
