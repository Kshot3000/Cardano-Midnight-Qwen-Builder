🧠 About this dashboard

Data: public NightForge explorer API (mainnet.nightforge.jp) — /api/blocks?limit=120 and /api/analytics/overview. The chain audit re-verifies every parent-hash link and height step in the fetched window entirely in your browser; the block health score is a transparent rubric (intact chain, contiguous heights, steady 6s cadence, fresh tip), computed in blocks.js and covered by 28 unit tests. Epoch progress assumes a 5-day Cardano epoch span when the epoch start is not exposed — the % and remaining minutes are then labeled as approximations. If the indexer stops exposing a field, this page shows – rather than inventing a number.

This is an informational tool over public chain data — verify anything security-critical against official Midnight sources before relying on it.
