🧠 About this data

Stats come from the public NightForge explorer API (mainnet.nightforge.jp) which indexes Midnight mainnet (node rpc.mainnet.midnight.network, indexer indexer.mainnet.midnight.network). The shielded ratio is the share of Midnight transactions where value is hidden by ZK proofs — the chain's core promise: selective disclosure, not no disclosure. Nothing private is ever exposed here.
