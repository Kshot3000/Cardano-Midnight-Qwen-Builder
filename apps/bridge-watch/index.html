ℹ️ What a "bridge op" is

A bridge operation is an extrinsic on Midnight that confirms a Cardano block header (or the assets/proofs inside it). One Cardano block can produce several ops — that ratio is shown above.

🧠 About this dashboard

Data: public NightForge explorer API (mainnet.nightforge.jp) — /api/analytics/bridge and /api/analytics/overview. The bridge health score is a transparent rubric (steady flow, sustained 24h volume, stable 12h-vs-12h trend, fresh observations), computed in bridge.js and covered by 26 unit tests. If the indexer stops exposing a field, this page shows – rather than inventing a number. No private data is involved — bridge operations are public on both chains.

Cardano data is the mainchain context the Midnight node tracks (epoch/slot). Bridge operations confirmed per Cardano block are derived from the recent operations window and labeled as such. This is an informational tool — verify amounts and finality against official sources before relying on them.
