📐 The method, honestly

Offchain DIDs embed their own state: did:midnight:offchain:<BLAKE2s-256 hash>:<base64url MOD1 state>. The resolver recomputes the hash from the state and rejects any mismatch — so a long DID is self-verifying the moment it lands, no registry lookup needed.

🧮 BLAKE2s-256, in the browser

Browsers don't ship BLAKE2s. The wallet carries a dependency-free, pure-JS BLAKE2s-256 that is cross-checked byte-for-byte against Node's native implementation across a full block-size sweep in the test suite — no WASM, no npm install.

🔑 Ledger DIDs

On-chain identities are did:midnight:<network>:<64-hex contract id> across undeployed / devnet / testnet / mainnet / preview / preprod. This wallet encodes and parses them; the contract state itself lives on-chain.
