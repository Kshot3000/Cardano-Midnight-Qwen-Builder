🧠 About this dashboard

Data: public NightForge explorer API (mainnet.nightforge.jp) — /api/analytics/privacy?hours=N (N up to 168) and /api/analytics/overview for lifetime context. The privacy health score is a transparent rubric (shielding dominant, sustained activity, stable flow, unshielded rare, self-consistent), computed in privacy.js and covered by 23 unit tests. The shielded ratio shown is recomputed from raw counts and cross-checked against the API-reported value; if the indexer stops exposing a field, this page shows – rather than inventing a number. No private data is involved — every unshielded transaction is public on the Midnight ledger.

"Shielded" means the transaction's inputs/outputs were processed through Midnight's shielded pool (zkSNARK-backed selective disclosure). Unshielded transactions are still valid Midnight transactions — they simply chose transparency (common for contract calls and token management ops). This is an informational tool — verify figures against the official explorer before relying on them.
