🧠 About this dashboard

Data: public NightForge explorer API (mainnet.nightforge.jp) — /api/block-producers?limit=200 (sampled blocks per producer with the indexer's own percentages), /api/analytics/block-rate?hours=24 (hourly block + extrinsic counts) and /api/governance/d-parameter (on-chain decentralization parameter history). All concentration figures are recomputed from raw block counts and cross-checked against the API-reported percentages (mismatch tolerance 0.5pp); the decentralization score is a transparent rubric, computed in producers.js and covered by 36 unit tests. If the indexer stops exposing a field, this page shows – rather than inventing a number.

Midnight's block producers are the permissioned candidate pool governed by the D-parameter: blocks are produced in a fixed cadence (6s), so share is about which validators are producing, not how fast. The producer sample window is set by the indexer (limit); shares are stable only over enough samples, which is why the health score gates on ≥100 sampled blocks. This is an informational tool — verify figures against the official explorer before relying on them.
