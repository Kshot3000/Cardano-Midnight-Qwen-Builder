🧠 About this dashboard

Data: public NightForge explorer API (mainnet.nightforge.jp) — /api/analytics/contracts (leaderboard + daily deployments) and /api/contracts/deployed (deploy-event stream). Every Midnight contract address is exactly 126 hex chars: 0x + the 30-byte ASCII tag midnight:contract-address[v2]: (60 hex) + a 32-byte digest (64 hex). The codec in address.js and the analytics in analyze.js are covered by 44 unit tests against real captured mainnet data. If the indexer stops exposing a field, this page shows — rather than inventing a number. Activity states: active called in the last 7 days, dormant 8–90 days, abandoned over 90 days, never called zero interactions.

This is an informational tool — verify amounts and finality against official sources before relying on them. Contract rows deep-link to the NightForge explorer.
