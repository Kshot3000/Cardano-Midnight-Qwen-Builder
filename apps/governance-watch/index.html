🧠 About this dashboard

Data: public NightForge explorer API (mainnet.nightforge.jp) — /api/governance. That endpoint reports the council and technical-committee proposal and vote events plus the authority (federated-membership) resets. The explorer emits each vote as a cumulative running tally (and a voter can re-vote), so this dashboard takes the tally from the latest vote event for each motion as the authoritative result. The governance health score is a transparent four-part rubric (motions being decided, quorum participation, a populated & rotating authority, and recent activity), computed in governance.js and covered by 31 unit tests. If the indexer stops exposing a field, this page shows – rather than inventing a number.

Motion hashes and voter / member SS58 keys are on-chain identifiers shown as-is — they are public, not personal data. The "approval threshold" is the size of the authority the motion is decided by. This is an informational tool; verify governance state against official sources before relying on it.
